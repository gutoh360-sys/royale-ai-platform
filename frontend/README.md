# Royale AI Platform — Frontend

## Desenvolvimento Local

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

### Rotas

| Rota | Descrição |
|------|-----------|
| `/` | Landing page |
| `/login` | Tela de login |
| `/app` | Dashboard Executivo |
| `/playground` | Developer Playground |

### Playground

Em `/playground`, visualize todos os componentes do Dashboard com controle de estados (Success/Loading/Empty/Error).
